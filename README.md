⭐ OOPS Banner Application
🔍 Project Overview

The OOPS Banner Application is a step-by-step Java console project built to showcase Object-Oriented Programming (OOP) concepts, clean coding standards, and incremental refactoring techniques.

The application begins with a basic console output (UC1) and gradually evolves into a flexible, reusable banner-rendering engine (up to UC8).
Throughout the evolution, advanced Java features such as arrays, methods, collections, HashMap, StringBuilder, and core OOP principles are applied.

🎯 Project Goals

➤ Render the word “OOPS” in a banner-style ASCII format
➤ Improve the implementation through multiple use cases
➤ Achieve modularity, reusability, and scalability
➤ Apply real-world OOP design principles
➤ Maintain clean architecture and readable code
